# Kimlik sağlayıcı varlıkları

Google G işareti, Google’ın [resmî kimlik varlığından](https://developers.google.com/static/identity/images/g-logo.png) değiştirilmeden alınmıştır; [Google giriş düğmesi yönergeleri](https://developers.google.com/identity/branding-guidelines) kapsamında kimlik sağlayıcısını belirtir. 200 × 204 RGBA PNG tam dosya olarak doğrulanmıştır.

Apple işaretinin path verisi [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg) projesindendir. CC0 lisansı `simple-icons.txt` dosyasındadır. Script/harici kaynak içermeyen yerel SVG kullanılır.

JWT doğrulaması php-jwt `v7.2.1` sürümüne sabitlenmiştir. Yedi kaynak dosyasının ve özel sunucu paketinin SHA-256 kayıtları `php-jwt-source.json`, BSD-3-Clause lisansı `php-jwt.txt` dosyasındadır. Özel imza anahtarları veya istemci sırları bu dosyalarda bulunmaz.
